2026-11-08 at commit 000f892ae9. Shiptest licenses its assets CC BY-SA 3.0
(https://creativecommons.org/licenses/by-sa/3.0/) unless a file says otherwise, and none of these

added by thearbiber in Shiptest PR #6745 ("New frontie/indie PDW: Heater and Scorcher"). Each DMI
holds only the states these guns use, copied pixel for pixel, apart from the renames listed.

Sounds
None copied. Shiptest's Heater fire and reload sounds (sound/weapons/gun/rifle/skm_smg.ogg,
sound/weapons/gun/smg/cm5_reload.ogg, cm5_unload.ogg) have no recorded source, so the guns use
/tg/station's own SMG and MOD flamethrower sounds instead.
